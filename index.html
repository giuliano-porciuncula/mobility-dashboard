Mobility Data Sources

This catalog documents 159 distinct data sources drawn from the human-mobility modeling literature, compiled as part of a broader review of how mobility is represented in epidemic simulation and where the underlying literature draws its data from. Starting from a small set of foundational citations, a citation-network snowball expanded the candidate literature to 24,216 papers, which were then screened down to 3,150 papers judged relevant to mobility representation or the data behind it.

Of those 3,150 papers, 2,055 contained a substantive statement of data requirements. Reading them identified 170 named data sources, excluding generic references with no identifiable source. These were cited across 330 papers, of which full text was retrieved for 325 (98.5%) through automated fetching, targeted browser retrieval, and manual access. Eleven pairs of sources turned out to describe the same underlying dataset or institution under different names and were merged, leaving the 159 distinct sources catalogued here, cited across 401 papers with verified full-text content.

Each entry records a source's scale, geographic and temporal coverage, stated limitations, methodological use, and access conditions. Sources are organized into fifteen categories by data type: fourteen covering observed data, plus a separate group for simulation and synthetic-population tools. A recurring pattern across the literature is that these sources are not interchangeable: studies comparing several sources for the same modeling task have found meaningfully different results depending solely on which one was used, and every major source carries some form of representativeness bias that is rarely disclosed with enough precision to correct for.
